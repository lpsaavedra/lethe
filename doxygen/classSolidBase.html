Detailed Description

template<int dim, int spacedim = dim>
class SolidBase< dim, spacedim >

A base class that generates a particle handler for the solid

Template Parameters
dimAn integer that denotes the dimension of the space in which the flow is solved
spacedimAn integer that denotes the dimension of the space occupied by the embedded solid

◆ move_solid_triangulation()

template<int dim, int spacedim>
void SolidBase< dim, spacedim >::move_solid_triangulation ( double time_step,
double initial_time )

Moves the vertices of the solid triangulation. This function uses an Runge-Kutta 4 explicit time integrator to displace the vertices of the solid triangulation and stores the displacement in an array in order to allow correct checkpointing of the triangulation. See https://en.wikipedia.org/wiki/Runge%E2%80%93Kutta_methods for more details.

Parameters
time_stepThe time_step value for this iteration
initial_timeThe initial time (time t) of the timestep. This is used to set the time of the velocity function.
