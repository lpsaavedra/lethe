Detailed Description

template<int dim>
class HeatFluxPostprocessor< dim >

Compute the local heat flux vector field within a domain.

The local heat flux is defined as \(\mathbf{q} = -k \nabla T\) where \(k\) is the thermal conductivity of the material and \(\nabla T\) the temperature gradient.

[in]p_idEither fluid ID or solid ID (as initialized in the physical properties). It is used to name the postprocessed variable vector.
[in]p_mesh_material_idIdentifier corresponding to the material as identified in the mesh. By convention, fluids are given the material_id 0 and solids follow with ids 1, 2, etc. This is used to identify which cell lies in which material.
[in]p_solid_phase_presentBoolean indicating if the simulation has solids. If there is no solid, the material_id of cells is not checked.
