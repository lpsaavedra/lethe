template<typename ScratchDataType, typename CopyDataType>
class PhysicsAssemblerBase< ScratchDataType, CopyDataType >

Base class for assembler objects of physics and subequations.

Template Parameters
ScratchDataTypeType of scratch data object used for linear system assembly.
CopyDataTypeType of copy data object used for transferring from local system assembly to global system.
