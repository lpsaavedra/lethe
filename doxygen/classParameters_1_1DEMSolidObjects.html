Detailed Description

template<int dim>
class Parameters::DEMSolidObjects< dim >

Container class managing rigid solid objects for DEM simulations.

This class holds two collections of RigidSolidObject instances: solid surfaces (2D boundaries) and solid volumes (3D bodies). It provides parameter declaration and parsing for the "solid objects" section of the parameter file.
