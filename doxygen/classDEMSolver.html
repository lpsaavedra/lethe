Detailed Description

template<int dim, typename PropertiesIndex>
class DEMSolver< dim, PropertiesIndex >

Solver using the soft-sphere model of the discrete element method (DEM) to simulate granular systems.

Template Parameters
dimAn integer that denotes the number of spatial dimensions.
PropertiesIndexIndex of the properties used within the ParticleHandler.

◆ box_refine_mesh()

template<int dim, typename PropertiesIndex>
void DEMSolver< dim, PropertiesIndex >::box_refine_mesh ( const bool restart)
private

Refine the triangulation within the user-specified refinement boxes.

Each box is described by its own mesh; every cell of the background triangulation that lies within a box is refined the number of times requested for that box. Nothing is done when restarting, since the triangulation stored in the checkpoint already carries its refinement.

Parameters
[in]restartFlag indicating whether this is a restart.

◆ synchronize_velocities()

template<int dim, typename PropertiesIndex>
void DEMSolver< dim, PropertiesIndex >::synchronize_velocities ( )
private

Carry out the closing half velocity step of a staggered integration scheme, which synchronizes the velocities of the particles with their positions at the final time. The contact forces are re-evaluated at the final position of the particles, hence n + 1 integration operations are carried out to complete n time steps.
