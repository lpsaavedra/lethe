template<int dim>
unsigned int MortarManagerBase< dim >::get_n_mortars ( ) const

Returns the number of mortar cells connecting rotor-stator regular cells at the interface 1 = rotor-stator meshes are aligned. Only one mortar cell is needed to connect each rotor-stator regular cell pair 2 = rotor-stator meshes are not aligned. Two mortar cells are linked to each rotor or stator regular cell.
